About all-OS

all-OS is a static operating-system directory. It uses no backend and can be hosted directly with GitHub Pages.

The search indexes the local catalog, including Linux distributions. Official buttons send you to the project or vendor website. No fake download mirrors are generated.

Keyboard: Ctrl/Cmd + K focuses search, arrows move through results, Enter opens a result, Esc closes overlays.
